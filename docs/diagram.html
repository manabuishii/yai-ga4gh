TRE の層(GA4GH の他の標準と TRE 全体)

上の 4 つの図の箱(太枠、「4 つの図にもある」)に、TRE(信頼できる研究環境)として要る箱・矢印と、連合の調整役の枠を足した図です。A 公式だけ=仕様・方針の文書に書いてあるもの、B 実装から=実装(OSS のコード・商用の文書)で動いていそうなもの、C 重ね合わせ=両方を重ねて「両方にある/公式だけ/実装だけ/どちらにも無い」を色で分けたもの。A では、誰が持つか決まっていない枠(計算の運用者・Broker の運営者・連合の調整役)は出ません(公式に決まっていないため)。箱・矢印・枠を押すと、確かさ・持ち主・出典・実装の根拠・TRE の問題が出ます。

公式の出典は 2026-10-16 の調べ(GA4GH の仕様・方針、Five Safes・SATRE・Five Safes RO-Crate・Data Visiting)、 実装の根拠は 2026-10-20 の調べ。図に入れた標準は 12(D-047)、残りは下の表に一覧だけ。 B-YAI-AUTH(yai の API の利用許可の発行口)は yai の都合の枠なので TRE の図には描かない。
